# Smile Care Dental

Welcome to the Smile Care Dental clinic website!

## Overview
This is a professional landing page showcasing dental services for Smile Care Dental in Casablanca, Morocco. The website provides information about services, our team, patient testimonials, and booking capabilities.

## Features
- Professional dental clinic presentation
- Mobile-responsive design
- Google Fonts integration
- Unsplash image integration
- SEO-optimized
- Modern and clean UI design
- Booking form functionality
- WhatsApp integration

## Structure
This repository contains a single HTML file (`index.html`) that represents the complete landing page for the clinic.

## Open Locally
Open the `index.html` file directly in your web browser to view the clinic website.
